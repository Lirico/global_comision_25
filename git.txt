

1. En primer lugar vamos a utilizar el comando "git init" para inicializar el repositorio
en el directorio actual.

2. Para vincularnos con un repositorio utilizamos el comando "git remote add origin <URL del repositorio>"

3. Para revisar que la vinculacion esta correctamente realizada utilizamos el comando "git remote -v".

4. Revisar que cambios estan para registrar con el comando "git status"

5. Si hay cambios para registrar los registramos con el comando "git add <nombre del archivo>" o "git add ."

6. Revisar que todo se registro correctamente volviendo a ejectuar "git status"

7. Para crear un backup rapido usamos el comando "git commit -m "mensaje de backup"

8. Para cambiarnos de versiones usamos el comando "git checkout <nombre de la version>"

9. Para enviar los cambios al repositorio vamos a utilizar el comando "git push"
